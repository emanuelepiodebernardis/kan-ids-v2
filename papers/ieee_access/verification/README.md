# Verification record scope

V012 records certify the current v0.12.0 manuscript build, table consistency, source/photo identities and visual inspection. `check_content_v012.py` verifies preserved scientific table rows, full-precision energy means, duplicate subgroup counts/metrics/certificates, historical AUROC and author/photo metadata. `render_V012_final/` contains all 23 final pages and contact sheets. No training, hardware rerun or absolute meter calibration is performed by these checks.

V010/V011 files, inherited `FINAL_SCIENTIFIC_QA.json`, `BASELINE_IDENTITIES.json`, `PACKAGE_MANIFEST_V010.json` and earlier rendered pages are preserved historical records. They do not certify v0.12.0. Current results are explicitly versioned V012.
