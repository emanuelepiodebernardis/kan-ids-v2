Thresholds and Learning in Adaptive Intrusion Detection
Reproduction package, 2 November 2026

The visible diagnostic names are A (operating policies and baseline audits),
B (matched CAL-role memory), and C (calibration eligibility and label reuse).
There are 55 initial-extension and 120/10/10 A/B/C cells: 195 recorded cells,
including 30 exact repeats. They are not independent stream replications.

CSV summaries are immediately available under analysis/. Executed sources,
models and full reports are under source/, with neutral directory names.
SOURCE_LEDGER.json preserves original execution paths and SHA-256 digests.
Restoring that layout is necessary because the executed Python imports,
recorded source digests and literal role salts are immutable provenance.
Historical internal paths do not indicate prior journal review.
Internal response documents, chats and author instructions are excluded.
Restoration creates a local Git snapshot so replay provenance commands work.
Its new local commit is not the original execution or public release commit.

From this directory, with Python 3:
  python restore_execution.py --out /path/to/empty/replay
  cd /path/to/empty/replay
  python adattamento-drift/review_extension/verify_artifacts.py
  python -m venv .venv
  .venv/bin/pip install -r adattamento-drift/review_extension/requirements.txt

On Windows replace .venv/bin/python and pip with .venv\Scripts\python.exe and
pip.exe. Set OPENBLAS_NUM_THREADS, OMP_NUM_THREADS and MKL_NUM_THREADS to 1.
The following POSIX shell variables shorten the commands:
  PY=.venv/bin/python
  EXT=adattamento-drift/review_extension

  $PY $EXT/rebuild_cache.py --data /path/to/data/ton --models $EXT/models/ton --cache /path/to/cache/ton --provenance $EXT/provenance/ton
