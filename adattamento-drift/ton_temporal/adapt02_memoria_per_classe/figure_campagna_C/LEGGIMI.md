# Figure ADAPT-02 campagna C

Le figure sono rigenerate dai 20 rendiconti completi della campagna C.
Non usano i dati grezzi e non includono D.

- `fpr_kan_complessivo_blocchi.png`: distingue il FPR complessivo dal FPR medio per blocco per KAN con memoria per classe.
- `differenze_appaiate_auroc.png`: differenze per-seme fra memoria per classe e FIFO sull'AUROC.
- `differenze_appaiate_recall_attacchi.png`: differenze per-seme sul recall degli attacchi.
- `differenze_appaiate_fpr_complessivo.png`: differenze per-seme sul FPR complessivo, in punti percentuali.
- `differenze_appaiate_fp.png`: differenze per-seme sui falsi allarmi.
- `differenze_appaiate_fn.png`: differenze per-seme sugli attacchi mancati.
